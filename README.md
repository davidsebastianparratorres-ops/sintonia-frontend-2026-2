

Proyecto React y Vite independiente. Incluye código ejecutable del home y catalogo, componentes funcionales, estilos por componente y tokens. 

## Ejecutar

Requiere Node.js 20.19 o posterior en la rama 20, o Node.js 22.12 o posterior.

```sh
npm ci
npm run dev
```

Abre la dirección que muestre Vite. Cada proyecto sirve su home en `/`.

```sh
npm run build
npm run preview
```
